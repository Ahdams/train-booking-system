# Train Booking System

Frontend prototype for a Nigerian railway booking system.

## Current features
- Route-only train search using daily schedules.
- Optional travel date and preferred time filtering.
- Passenger accounts with password visibility controls.
- Account-specific My Bookings.
- Account-specific E-Wallet.
- E-Wallet transaction history.
- Seat selection and booking payment.
- Booking lifecycle: Confirmed, Completed, Cancelled.
- 90% cancellation refund to the booking owner's wallet.
- Passenger reports and admin resolution workflow.
- Admin dashboard with booking, passenger, schedule and report management.
- Admin-created train schedules.
- Promo codes and travel classes.
